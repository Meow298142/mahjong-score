# 日麻算点 · 役种图鉴与点数计算

**在线地址：<https://meow298142.github.io/mahjong-score/>**
仓库：<https://github.com/Meow298142/mahjong-score>

纯静态、无依赖、无广告、无登录。首页是**役种图鉴**，算点台与点数表在上方导航里。规则基准为天鳳，另带雀魂 / M-League 预设。

## 三个页面

- **役种图鉴**（`#yaku`，首页）：43 个役种的中文说明与番数，含副露降番，可按番数筛选与搜索。
- **算点台**（`#calc`）：从牌库点选 14 张手牌（有副露时 13 张），点一张设为和了牌，右侧直接出番数、符数与点数；支持吃 / 碰 / 明杠 / 暗杠、宝牌与里宝牌、本场与供托、立直一发抢杠海底河底。
- **点数表**（`#table`）：子家 / 亲家 × 荣和 / 自摸，1-4 番按符展开，5 番以上合并为满贯 / 跳满 / 倍满 / 三倍满 / 役满。

深链可用：`#yaku` `#calc` `#table`，`#demo` 会载入一副 4 番 30 符 7700 点的示例手牌。

## 本地打开

双击 `index.html` 即可离线使用（file:// 下全部功能可用，只是浏览器会缓存 `app.js`，改完加 `?v=N` 再开）。

## 怎么更新线上版本

1. 改本地的 `index.html` / `styles.css` / `app.js` / `engine.js`；
2. 打开仓库页 → **Add file → Upload files**，把这几个文件一起拖进去（同名会覆盖）；
3. 提交后等 1-2 分钟，Pages 会自动重建；浏览器强刷（Ctrl+F5）即可看到新版。

## 文件

| 文件 | 职责 |
|---|---|
| `index.html` | 页面结构，三个 tab |
| `styles.css` | 和纸米色底 + 深绿 + 朱红；960px / 620px 两个断点 |
| `app.js` | 界面逻辑（单个 IIFE、经典 script、无构建） |
| `engine.js` | 算点引擎：手牌分解、役种判定、符计算、点数换算、规则开关 |
| `.nojekyll` | 让 GitHub Pages 跳过 Jekyll 处理 |
| `favicon.svg` `og.png` `404.html` | 图标 / 分享卡片图 / 404 页 |
