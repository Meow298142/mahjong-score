# 日麻算点 · 役种图鉴与点数计算

纯静态、无依赖、无广告、无登录。首页是**役种图鉴**，算点台和点数表在上面导航里。

## 两种用法

**① 自己电脑直接看**：双击 `index.html`（离线可用）。

**② 手机 / 平板 / 另一台电脑看**：双击 `启动服务器.bat`（或在该目录执行 `node server.js 8080`），
控制台会打印两个地址：

    本机:   http://localhost:8080/
    局域网: http://192.168.x.x:8080/

手机连同一个 Wi-Fi，浏览器打开局域网那条地址即可。Windows 第一次会弹防火墙提示，选「允许」；
若手机打不开，用管理员 PowerShell 执行一次：

    New-NetFirewallRule -DisplayName "日麻算点 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow

> 服务器要一直开着手机才访问得到。关掉窗口即停止。

## 做成真正的网站（公网）

站点是纯静态的，`dist/` 里的 7 个文件就是完整站点，任选一种方式托管：

1. **Netlify Drop**（最快，无需账号）：打开 app.netlify.com/drop，把 `dist` 文件夹拖进去，几秒后拿到 `https://xxx.netlify.app` 地址。
2. **Cloudflare Pages**：上传 `dist`，绑定自定义域名免费。
3. **GitHub Pages**：把 `dist` 内容推到仓库，Settings → Pages 选 main 分支。

也可以直接把 `日麻算点-静态站.zip` 交给任何静态托管服务上传。

上传后 `#yaku` `#calc` `#table` `#demo` 深链照常可用，404 页会自动生效（Netlify/Cloudflare 默认支持 404.html）。

## 文件

- `index.html` —— 页面结构，三个 tab：役种图鉴（默认）/ 算点台 / 点数表
- `styles.css` —— 和纸米色 + 深绿 + 朱红；960px / 620px 两个断点
- `app.js` —— 界面逻辑（单个 IIFE，经典 script，无构建）
- `engine.js` —— 算点引擎（手牌分解、役种判定、符计算、点数表）
- `engine.test.js` —— 14 条回归用例，`node engine.test.js`
- `server.js` —— 40 行的静态服务器（no-store，避免改完代码手机还看旧的；404 走 404.html）
- `favicon.svg` / `og.png` / `404.html` —— 图标、分享卡片图、404 页
- `dist/` —— 可直接上传的纯静态站点（7 个文件）

## 用法

1. 切到「算点台」
2. 从牌库点选 14 张手牌（有副露时按 13 张算）
3. 点手牌中一张，标成「和了牌」
4. 结果卡实时显示点数、番符、役种、符明细与牌型分解；窄屏下底部有一条常驻结果条

副露：点「录入副露」→ 选吃/碰/明杠/暗杠 → 在牌库点牌 → 「加入副露」。
宝牌：点「+ 宝牌指示」选指示牌，下方自动换算实际宝牌（7m → 8m，9p → 1p，中 → 白）。

深链：`#yaku` `#calc` `#table` 直接打开对应页面，`#demo` 载入示例手牌。

## 已支持的规则项

- 天鳳为基准，另附雀魂（切上满贯）、M-League 预设
- 门前清 / 副露、荣和 / 自摸、亲家 / 子家
- 立直、双立直、一发、岭上、抢杠、海底、河底
- 役种全表（含食い下がり），役满与双倍役满（国士十三面、四暗刻单骑）
- 符：副底、门前荣和 +10、自摸 +2、雀头、刻子/杠子（中张/幺九、明/暗）、平和自摸固定 20 符、七对子 25 符、食い平和形 20 符、切上满贯开关
- 本场（+300/本场）、供托（+1000/本）
- 四暗刻双碰荣和自动降为三暗刻
